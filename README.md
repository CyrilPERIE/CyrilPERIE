Je développe des applications web fullstack complexes, de la collecte et du traitement de données jusqu'à leur restitution dans des interfaces modernes.

#### Projets

- [tallys-server](https://github.com/CyrilPERIE/tallys-server) — Serveur qui récupère, traite, modélise et sert les données issues de [PMU](https://pmu.fr).
- [tallys-app](https://github.com/CyrilPERIE/tallys-app) — Application React proposant des tableaux de bord pour explorer et visualiser les données de `tallys/server`.

#### Stack

TypeScript · React · Node.js · PostgreSQL · Docker
